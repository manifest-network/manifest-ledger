# Mutation reproduction — 2026-09-11

These bundled reruns replace the three previously archived export/withdrawal
mutant logs and their two controls. The original logs established narrower
failures but did not record enough command and mutation provenance. The
September 10 reruns added that provenance; these September 11 reruns verify
reproduction from bundled inputs without requiring the historical Git objects.
Other validation artifacts in the parent directory remain historical and were
not regenerated by this script.

The entire source and test tree comes from the bundled `git archive` of baseline
`b4d8403977b8f18eeaad699239e9661efa2a4a8a`. The compressed snapshot is about
1.4 MB. Its uncompressed SHA-256 remains
`235e4171af8b0581fff909ac1613efef183ef1fad78b3fcfc5c81d566e4130ef`,
identical to the September 10 archive. The mutations do not overwrite
checkout source files or shared SDK source files. The two historical source-file replacements come from
`4b89fdacb8d840b074ffda3e64efb34f5a4b71b3`; the shallow mutant deletes only
the `cloneLeaseReservation` assignment from the baseline withdrawal helper.
The mutations change source files through Go overlays. The archived snapshot
itself remains unchanged. The [input manifest](inputs/manifest.json) records
the compressed and uncompressed archive hashes and both historical source-file
hashes; the driver checks those hashes before using the bundled inputs. A squash
merge does not require retaining the PR branch or either historical commit to
run this bundled mode.

Every run uses `go test -p 2 … -count=1 -timeout=180s -v` with
`GOTOOLCHAIN=go1.26.8`, `GOMAXPROCS=4`, `GOWORK=off`, `GOFLAGS=-mod=readonly`,
and a temporary build directory inside the isolated snapshot. The ellipsis
here is explanatory: [runs.json](runs.json) records each complete command,
argument array, environment override, working directory, timestamps, and
observed exit status. It also records the Go version, source archive hash,
relevant test/source hashes, raw and display log hashes, test names run and failed, and
the check that archived source files stayed unchanged.

Display logs expand tabs to eight-column stops and strip trailing whitespace
per line before hashing and archiving. They preserve all verbose test output.
Each `*-raw.json` file stores the exact UTF-8 stdout/stderr string, including
its original whitespace; the manifest records both that string's byte hash
and the JSON file's hash. No patch or source file is whitespace-normalized.

The overlay maps and commands preserve the absolute paths from the recorded
run. To reconstruct the same source changes at new paths, run the checked-in
[driver](reproduce.py), which rebuilds the snapshot, patches, maps, logs, and
manifest from the bundled inputs. Python 3.12 or newer and Go are required;
the recorded run used Python 3.14.7. Git is optional for bundled reproduction;
it is needed only for the alternative Git-object mode or manual patch checks.
Go may need its normal module
and toolchain cache access, and SDK fixtures bind localhost sockets.
The patches have zero context to avoid whitespace-only context lines; manual
application with Git requires `git apply --unidiff-zero`. The driver generates
the same mutated bytes from the bundled historical files and the single-line
deletion, and records hashes for both the files and their patches.
[Independent patch reconstruction](patch-reconstruction-checks.json) also
applies each recorded patch in a fresh scratch repository and verifies that
the reconstructed file matches its recorded mutant hash.

Run from a checkout or source tree containing this driver and its `inputs/`
directory, choosing a new work directory and a separate output directory:

```bash
python3 docs/reviews/2026-09-10-claude-follow-up-review-validation/mutation-provenance/reproduce.py \
  --bundled .review-tmp/reproduce-pr179-mutations .review-tmp/reproduced-pr179-evidence
```

The driver refuses to reuse its work directory. Bundled mode reads only its
local inputs and writes the requested work/evidence directories, while Go
uses its normal caches. The optional Git-object mode replaces `--bundled` with
a repository path containing both pinned commits and reads those Git objects.
Test timing and generated fixture addresses can vary; the baseline
commit, mutation hashes, selected tests, and pass/fail outcomes are the stable
reproduction contract. A mutant's exit 1 is an expected regression-test
failure, not a passing test run.
